## 練習 1：describe

```rust
impl Transaction {
    fn describe(&self) -> String {
        let (verb, abs) = if self.amount.0 >= 0 {
            ("存入", self.amount)
        } else {
            ("提出", Money(-self.amount.0))
        };
        format!("#{} 帳戶 {} {} {}（{}）", self.id, self.account_id, verb, abs.format(), self.memo)
    }
}
```

輸出：`#1 帳戶 1001 存入 50000.00 元（十月薪資）`。
`if` 是表達式，可以直接產出一個 tuple 再解構，不用先宣告兩個 `mut` 變數。

## 練習 2：Ledger 與 find_account

```rust
struct Ledger {
    accounts: Vec<Account>,
    transactions: Vec<Transaction>,
}

impl Ledger {
    fn find_account(&self, id: u32) -> Option<&Account> {
        self.accounts.iter().find(|a| a.id == id)
    }
}
```

**為什麼回傳 `Option<&Account>` 而不是 `Option<Account>`**：

- `Account` 含 `String`，回傳值就要 `clone`，配置新記憶體，而呼叫端通常只是看一眼
- 借用的語義更正確：帳戶仍然屬於帳本，呼叫端只是暫時查看（第 3 章）
- 如果呼叫端真的需要擁有一份，它可以自己 `.cloned()`。把決定權留給呼叫端

這個簽名用了省略規則：回傳的引用生命週期跟 `&self` 一樣（第 10 章）。

## 練習 3：具名欄位版 Money

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
struct MoneyNamed { cents: i64 }

let m = MoneyNamed { cents: 25_050 };
m.cents
```

比較：

| | `Money(i64)` | `Money { cents: i64 }` |
|---|---|---|
| 建構 | `Money(100)` 簡潔 | `Money { cents: 100 }` 囉嗦 |
| 存取 | `m.0` 不好讀 | `m.cents` 清楚 |
| 可以直接當函式 | `.map(Money)` | 不行 |

經驗法則：**只有一個欄位且意義不言自明（newtype）用元組結構體；兩個以上欄位用具名**。
實務上 newtype 的 `.0` 很少出現在外部程式碡，因為它是私有的（第 8 章），外部透過 `.cents()` 方法存取，所以可讀性問題不大。
