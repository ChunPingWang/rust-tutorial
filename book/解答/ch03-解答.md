## 練習 1：find

```rust
fn find(memos: &[String], keyword: &str) -> Option<usize> {
    for (i, m) in memos.iter().enumerate() {
        if m.contains(keyword) {
            return Some(i);
        }
    }
    None
}
```

- 回傳 `Option<usize>`：找不到是正常情況，不是錯誤，用 `None` 表達
- 兩個參數都是借用：函式只讀不存
- 第 7 章的迭代器版本是一行：`memos.iter().position(|m| m.contains(keyword))`

## 練習 2：apply_interest

```rust
fn apply_interest(amounts: &mut [i64], rate_bp: i64) {
    for a in amounts.iter_mut() {
        if *a > 0 {
            *a += *a * rate_bp / 10_000;
        }
    }
}
```

- `&mut [i64]` 切片而不是 `&mut Vec<i64>`：不改長度，切片就夠，而且陣列也能傳進來
- `iter_mut()` 產生 `&mut i64`，要用 `*a` 解引用才能讀寫
- 1 bp = 0.01% = 1/10,000，整數運算先乘再除避免精度損失

## 練習 3：兩個借用錯誤

```rust
let mut v = vec![1, 2, 3];

let r1 = &mut v;
let r2 = &mut v;     // error[E0499]: cannot borrow `v` as mutable more than once at a time
r1.push(4);
r2.push(5);
```

E0499 的訊息會標出「first mutable borrow occurs here」與「second mutable borrow occurs here」，以及 r1 在哪裡被最後使用。
如果把 `r1.push(4)` 移到 `let r2` 之前，就不會錯：r1 的借用在最後一次使用時結束（NLL）。

```rust
let first = &v[0];
v.push(4);           // error[E0502]: cannot borrow `v` as mutable because it is also borrowed as immutable
println!("{first}");
```

E0502 的訊息三段：「immutable borrow occurs here」「mutable borrow occurs here」「immutable borrow later used here」。
第三段是關鍵：如果 `first` 之後沒再被用，就沒有錯誤。解法是把 `println!` 移到 `push` 之前。
