## 練習 1：千分位

思路：先把整數部分轉成字串，從左邊走，每當「剩下的位數」是 3 的倍數且不是開頭，就先放一個逗號。

```rust
fn format_money(cents: i64) -> String {
    let sign = if cents < 0 { "-" } else { "" };
    let yuan = (cents / 100).abs();
    let fen = (cents % 100).abs();
    let digits = yuan.to_string();
    let mut grouped = String::new();
    for (i, ch) in digits.chars().enumerate() {
        if i > 0 && (digits.len() - i) % 3 == 0 {
            grouped.push(',');
        }
        grouped.push(ch);
    }
    format!("{sign}{grouped}.{fen:02} 元")
}
```

`format_money(175_050)` → `1,750.50 元`；`format_money(-123_456_789)` → `-1,234,567.89 元`。

這題會提早遇到 `String` 的 `push`、`chars()`、`enumerate()`。第 7 章學完迭代器後可以改寫成 `rev().chunks(3)` 的版本，但這個迴圈版已經很清楚。

## 練習 2：apply

```rust
fn apply(balance: i64, delta: i64) -> i64 {
    if delta < 0 && -delta > balance {
        println!("提款 {} 失敗：餘額不足", format_money(-delta));
        return balance;
    }
    balance + delta
}
```

`main` 裡原本兩段加減變成 `balance = apply(balance, 25_050); balance = apply(balance, -200_000);`。
注意 `apply` 接收 `i64` 回傳 `i64`，不修改任何東西：這是「純函式」，容易測試。第 6 章會把印訊息改成回傳 `Result`。

## 練習 3：溢位

```rust
let x: i32 = 2_147_483_647;
let y = x + 1;
```

- `cargo run`（debug）：`panic: attempt to add with overflow`，程式中止
- `cargo run --release`：`y = -2147483648`，靜默繞回

兩種行為對帳本都是錯的。正確做法是明確處理：

```rust
match x.checked_add(1) {
    Some(v) => println!("{v}"),
    None => println!("i32 溢位被 checked_add 攔下"),
}
```

`checked_add` 回傳 `Option<i32>`，溢位是 `None`。另有 `saturating_add`（卡在最大值）與 `wrapping_add`（明確要繞回）。帳本一律用 `checked_*`。
