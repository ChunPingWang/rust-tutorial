## 練習 1：make_memo

```rust
fn make_memo(kind: &str, amount: i64) -> String {
    format!("{kind} {}.{:02} 元", amount / 100, amount % 100)
}
```

**為什麼參數用 `&str`**：函式只是讀 `kind`，不需要擁有它。用 `&str` 讓呼叫端可以傳字面值 `"存款"`、也可以傳 `&some_string`，最通用。
**為什麼回傳 `String`**：`format!` 產生的是**新的**資料，函式結束後必須有人擁有它，否則就被釋放了。回傳 `&str` 會是「回傳對區域變數的引用」，編譯錯誤 E0515（第 10 章）。

經驗法則：**借進來，擁有出去**。

## 練習 2：tuple 是不是 Copy

```rust
let holder = (1001u32, String::from("王小明"));
let moved = holder;
// println!("{:?}", holder);   // error[E0382]: borrow of moved value: `holder`
```

`(u32, String)` **不是** Copy。tuple 只在「所有元素都是 Copy」時才是 Copy；`String` 擁有堆積記憶體，不是 Copy，所以整個 tuple 跟著不是。

對照 `(u32, &str)`：`&str` 是借用，是 Copy，所以這個 tuple 是 Copy，賦值後兩邊都能用。

判斷方法只有一個：**這個型別有沒有需要釋放的資源？有，就不能是 Copy。**

## 練習 3：還回兩個 String

```rust
fn record_two(first: String, second: String) -> (String, String) {
    println!("已記錄：{first}、{second}");
    (first, second)
}

let (a, b) = record_two(a, b);     // 呼叫端要解構再重新綁定
```

每呼叫一次都要寫 `let (a, b) = ...`，三個參數就更糟。這就是借用存在的理由：第 3 章的版本只要 `record_two(&a, &b)`，呼叫完 `a`、`b` 自然還在。
