# 第 10 章練習解答

完整可編譯版本：`code/solutions/ch10/`。

## 練習 1：filter_kind

```rust
impl<'a> Statement<'a> {
    pub fn filter_kind(&self, label: &str) -> Vec<&'a Transaction> {
        self.entries.iter().copied().filter(|tx| kind_label(&tx.kind) == label).collect()
    }
}
```

回傳 `Vec<&'a Transaction>` 而不是 `Vec<&Transaction>`：元素借自**帳本**（`'a`），不是借自 `Statement`。這樣呼叫端可以 `let transfers = stmt.filter_kind("轉帳"); drop(stmt);` 之後繼續用 `transfers`。
如果省略寫成 `Vec<&Transaction>`，省略規則會把它綁到 `&self`，功能上也能用，但限制比實際需要的嚴。**標註的目的是說真話**：這些引用實際借自誰。

一個小陷阱：第一版把參數命名為 `kind_label`，與同名函式衝突，編譯器報「expected function, found `&str`」。區域變數會遮蔽同名函式。

## 練習 2：split_memo

```rust
pub fn split_memo(memo: &str) -> (&str, &str) {
    match memo.find(' ') {
        Some(i) => (&memo[..i], memo[i + 1..].trim_start()),
        None => (memo, ""),
    }
}
```

**不需要**標註。只有一個輸入引用，省略規則 2 把所有輸出引用都綁到它。回傳 tuple 裡的兩個 `&str` 都借自 `memo`。
`""` 字面值是 `&'static str`，可以縮短成任何生命週期，所以 `None` 分支的型別也對得上。

## 練習 3：把回傳改成 `Option<&str>`

```rust
pub fn next_word(&mut self) -> Option<&str>     // 省略規則 3：綁到 &mut self
```

呼叫端：

```rust
while let Some(w) = parser.next_word() {
    words.push(w);         // w 借著 parser（&mut）
}                          // 下一圈再呼叫 next_word → E0499: cannot borrow `parser` as mutable more than once
```

錯誤訊息會指出第一次可變借用在 `parser.next_word()`，而 `words` 持有的 `w` 讓它一直活著。改回 `Option<&'s str>` 就好：告訴編譯器 `w` 借的是原始字串，與 parser 無關。

這是一個**標註放寬限制**的例子，不是收緊。

## 練習 4：實作 Iterator

```rust
impl<'s> Iterator for MemoParser<'s> {
    type Item = &'s str;
    fn next(&mut self) -> Option<Self::Item> {
        self.next_word()
    }
}
```

只要實作 `next`，就免費獲得 `for` 迴圈、`collect`、`count`、`filter`、`map`……所有迭代器方法：

```rust
let words: Vec<&str> = MemoParser::new(&memo).collect();
MemoParser::new(&memo).filter(|w| w.len() > 1).count()
```

`type Item = &'s str` 是關聯型別（第 9 章）：這個迭代器產生的元素型別。注意它帶著 `'s`，所以收集出來的 `Vec<&str>` 也借自原始字串。
