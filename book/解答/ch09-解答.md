## 練習 1：JsonReport

```rust
pub struct JsonReport;

impl ReportFormat for JsonReport {
    fn render(&self, ledger: &Ledger) -> String {
        let items: Vec<String> = ranking(ledger).iter()
            .map(|(id, owner, bal)| format!("{{\"account_id\":{id},\"owner\":{owner:?},\"balance_cents\":{}}}", bal.cents()))
            .collect();
        format!("{{\"total_cents\":{},\"accounts\":[{}]}}\n", ledger.total_balance().cents(), items.join(","))
    }
    fn file_extension(&self) -> &'static str { "json" }
}
```

`{owner:?}` 用 Debug 格式印字串，會加引號並跳脫特殊字元，剛好接近 JSON 字串的規則（但不完全相同，例如 Unicode 跳脫方式不同）。這就是為什麼第 12 章要換 serde：手工拼 JSON 在邊界情況會出錯。

加進 `render_all` 的清單只要多一行 `Box::new(JsonReport)`，其他程式碼不動。這就是 trait object 的價值。

## 練習 2：Mul<i64>

```rust
impl Mul<i64> for Money {
    type Output = Money;
    fn mul(self, rhs: i64) -> Money {
        Money(self.0.checked_mul(rhs).expect("Money 乘法溢位"))
    }
}
```

`Mul<i64>` 的泛型參數指定右操作數的型別。**不要**實作 `Mul<Money> for Money`：金額乘金額沒有單位意義（元²）。沒實作的話，`Money::from_yuan(1) * Money::from_yuan(1)` 是編譯錯誤 E0369，這正是型別系統在幫你擋住無意義的運算。

同理，`Money / i64` 合理（平分），`Money / Money` 得到的是比率（`f64` 或純數字），不是 `Money`，若要實作，`Output` 應該是 `f64`。

## 練習 3：FromStr for TxKind

```rust
impl FromStr for TxKind {
    type Err = ParseTxKindError;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        let err = || ParseTxKindError(s.to_string());
        let parts: Vec<&str> = s.split(':').collect();
        let id = |i: usize| -> Result<u32, _> { parts.get(i).ok_or_else(err)?.parse().map_err(|_| err()) };
        match (parts.first().copied(), parts.len()) {
            (Some("D"), 2) => Ok(TxKind::Deposit { account: id(1)? }),
            (Some("W"), 2) => Ok(TxKind::Withdraw { account: id(1)? }),
            (Some("X"), 3) => Ok(TxKind::Transfer { from: id(1)?, to: id(2)? }),
            _ => Err(err()),
        }
    }
}
```

實作了 `FromStr`，`"D:1001".parse::<TxKind>()` 就能用，第 12 章的 clap 也能直接把命令列參數解析成 `TxKind`。
`match` 同時比對第一個元素與長度，讓 `"D:1:2"`（多餘欄位）也被拒絕。測試要涵蓋每種合法格式與至少五種非法格式。

## 練習 4：save_and_verify

```rust
pub fn save_and_verify(storage: &mut impl Storage, ledger: &Ledger) -> Result<bool, StorageError> {
    storage.save(ledger)?;
    let restored = storage.load()?;
    Ok(restored == *ledger)
}
```

`&mut impl Storage` 是泛型的簡寫，編譯期為每種 Storage 各生成一份。對 `InMemoryStorage` 與 `TextFileStorage` 都能呼叫。
`restored == *ledger`：`restored` 是 `Ledger`，`ledger` 是 `&Ledger`，要解引用才能比較（或寫 `&restored == ledger`）。這依賴 `Ledger` derive 了 `PartialEq`。
