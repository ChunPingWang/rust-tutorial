## 練習 1：is_new_counterparty

```rust
let mut counterparties: HashMap<u32, HashSet<u32>> = HashMap::new();
// 迴圈內
let is_new_counterparty = match tx.kind {
    Kind::Transfer => {
        let counterparty = ...;                               // 對象帳戶
        let seen = counterparties.entry(tx.account).or_default();
        if seen.insert(counterparty) { 1.0 } else { 0.0 }     // insert 回傳「之前沒有」
    }
    _ => 0.0,
};
```

`HashSet::insert` 回傳 `bool`，剛好是「第一次出現」。合成資料沒有「對象帳戶」欄位，解答用 `金額 % 50` 當替身示範計算方式，所以差距只有 +0.46；真實資料裡「轉給從沒轉過的人」通常是強特徵。
`FEATURE_NAMES` 從 9 變 11，`Array2::zeros((n, FEATURE_NAMES.len()))` 自動跟著變，這是用常數而不是寫死 9 的好處。

## 練習 2：velocity_1h vs velocity_24h

```
is_new_counterparty    正常 -0.016  詐欺 +0.447  差距 +0.464
velocity_1h            正常 -0.110  詐欺 +3.021  差距 +3.131
velocity_24h           正常 -0.042  詐欺 +1.147  差距 +1.189
```

1 小時窗口的差距是 24 小時的 2.6 倍。合成資料的詐欺是「被盜用後幾分鐘內連續 1 到 4 筆」，24 小時窗口把這個訊號和正常的日常交易混在一起稀釋了。
特徵的時間窗口要跟著現象的時間尺度選，而且可以同時放多個窗口（1h、24h、7d）讓模型自己挑。

## 練習 3：帳戶平均特徵矩陣

```rust
pub fn account_profiles(txs: &[LabeledTx], x: &Array2<f64>) -> (Array2<f64>, Vec<u32>) {
    let mut groups: HashMap<u32, Vec<usize>> = HashMap::new();
    for (i, tx) in txs.iter().enumerate() {
        groups.entry(tx.account).or_default().push(i);
    }
    let mut ids: Vec<u32> = groups.keys().copied().collect();
    ids.sort();                                                      // 固定順序
    let mut m = Array2::<f64>::zeros((ids.len(), x.ncols()));
    for (r, id) in ids.iter().enumerate() {
        m.row_mut(r).assign(&x.select(Axis(0), &groups[id]).mean_axis(Axis(0)).unwrap());
    }
    (m, ids)
}
```

`select` 挑出該帳戶的所有列，`mean_axis(Axis(0))` 壓成一列，`row_mut(r).assign` 寫進結果。240 個帳戶 × 11 個特徵。這就是 ML-3 K-means 的輸入。
回傳 `ids` 是為了之後能把「第 r 列」對回帳戶 ID；`HashMap` 的迭代順序隨機，一定要排序。

## 練習 4：min-max vs z-score

```
min-max：98.4% 的資料被壓在 0..0.3（最大值 30 把範圍拉得很寬）
z-score：84.3% 的資料落在 -1..1
amount_vs_acct 的詐欺/正常平均差距：min-max 0.105 vs z-score 2.417
```

`amount_vs_acct` 最大值 30 是極端值。min-max 用它當分母，絕大多數正常資料被壓進 0 到 0.3 的窄區間，詐欺與正常的差距縮到 0.1，模型幾乎看不出來。z-score 用標準差當分母，單一極端值的影響小得多。

| 標準化 | 適合 | 不適合 |
|---|---|---|
| z-score | 大多數情況，特別是有離群值 | 需要固定範圍（例如餵給 sigmoid 的像素） |
| min-max | 有明確上下界的欄（hour、百分比） | 有離群值 |
| robust（中位數 / IQR） | 離群值很多 | 需要保留極端值的意義時 |

兩種 Scaler 介面相同（`fit` / `transform`），換掉只改一行，這是第 9 章「同一介面多種實作」的 ML 版本。
