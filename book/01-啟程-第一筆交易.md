# 第 1 章　啟程：第一筆交易

> **場景**：產品經理走過來說：「新系統先不用做什麼，能收一筆存款、印出餘額就好。」
> 聽起來簡單，但我們第一步就要做一個會影響整個系統的決定：**錢要用什麼型別存？**

## Why：為什麼第一章就談型別

在很多語言裡，第一個程式是 `print("Hello")`，型別是之後的事。
但帳本系統的第一個決定就是型別決定：金額用什麼存？
前言提過舊系統的浮點數事故。這一章我們會親眼看到問題，並做出正確的選擇。
順便，你會學會 Rust 的安裝、專案工具 `cargo`、變數與基本型別。

## What：Rust 的工具鏈與基本型別

### 安裝

Rust 官方的安裝工具叫 `rustup`，它會同時安裝：

- `rustc`：編譯器
- `cargo`：套件管理 + 建置工具 + 測試執行器，你 99% 的時間都在用它
- `rustup` 自己：管理多個版本的工具鏈

```bash
# macOS / Linux
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Windows：到 https://rustup.rs 下載 rustup-init.exe
```

安裝完確認：

```bash
rustc --version
cargo --version
```

編輯器建議裝 **rust-analyzer**（VS Code 直接搜尋擴充套件）。它會即時顯示型別推導結果與編譯錯誤，
對學習 Rust 的幫助非常大，因為你可以把游標移到變數上就看到編譯器認為它是什麼型別。

### 建立專案

```bash
cargo new ledger
cd ledger
```

產生的結構：

```
ledger/
├── Cargo.toml   # 專案設定與相依套件，相當於 package.json / pyproject.toml
└── src/
    └── main.rs  # 程式入口
```

`Cargo.toml` 長這樣：

```toml
[package]
name = "ledger"
version = "0.1.0"
edition = "2021"   # 語言版本，不是編譯器版本。2021 是目前最常用的

[dependencies]
```

常用的 cargo 指令：

| 指令 | 作用 |
|---|---|
| `cargo run` | 編譯並執行 |
| `cargo build` | 只編譯（debug 模式，在 `target/debug/`） |
| `cargo build --release` | 最佳化編譯，第 16 章會用 |
| `cargo check` | 只檢查能不能編譯，不產生執行檔，**最快**，寫程式時常按 |
| `cargo test` | 執行測試，第 11 章 |
| `cargo fmt` | 自動排版 |
| `cargo clippy` | 靜態檢查，會給你更好的寫法建議 |

### 變數：預設不可變

```rust
let balance = 100;      // 不可變
balance = 200;          // 編譯錯誤：cannot assign twice to immutable variable

let mut balance = 100;  // 加 mut 才能改
balance = 200;          // OK
```

**為什麼預設不可變？** 因為在帳本系統裡，大部分的值一旦建立就不該變：交易金額、交易時間、帳戶 ID。
會變的只有餘額這類狀態。預設不可變讓「這個值會被改」變成一件需要明說的事，讀程式的人一眼看到 `mut` 就知道要小心。

### 基本型別

Rust 是靜態強型別語言，但大多時候你不必寫型別，編譯器會推導。

| 類別 | 型別 | 用途 |
|---|---|---|
| 有號整數 | `i8` `i16` `i32` `i64` `i128` `isize` | 數字後面是位元數；`isize` 跟指標一樣寬 |
| 無號整數 | `u8` `u16` `u32` `u64` `u128` `usize` | 不能為負；`usize` 用於索引與長度 |
| 浮點數 | `f32` `f64` | 科學計算用，**不要存錢** |
| 布林 | `bool` | `true` / `false` |
| 字元 | `char` | 一個 Unicode 碼位，4 bytes，`'王'` 是合法的 char |
| 字串切片 | `&str` | 字串的「借用視圖」，字面值 `"abc"` 是這個型別 |
| 字串 | `String` | 擁有所有權、可成長的字串 |
| 單元 | `()` | 「沒有值」，相當於 void |

整數預設是 `i32`，浮點數預設是 `f64`。數字中可以用 `_` 分隔方便閱讀：`150_000`。

**整數溢位**：debug 模式下溢位會 panic（程式中止並報錯），release 模式下會繞回（wrap）。
對帳本來說兩種都不對，第 9 章我們會用 `checked_add` 這類方法明確處理。這也是為什麼餘額要用 `i64` 而不是 `i32`：
`i32` 的上限約 21 億分，也就是 2,147 萬元，一個中型公司的帳戶就會爆掉。`i64` 的上限是 9.2 × 10^16 分，夠用。

### 函式

```rust
fn format_money(cents: i64) -> String {
    let yuan = cents / 100;
    let fen = (cents % 100).abs();
    format!("{yuan}.{fen:02} 元")   // 最後一個表達式沒有分號 = 回傳值
}
```

- 參數**必須**標型別，回傳型別用 `->`
- 函式本體最後一個**沒有分號的表達式**就是回傳值，`return` 只在提早返回時用
- Rust 是「表達式導向」的語言：`if`、`match`、`{}` 區塊都有值

```rust
let status = if withdraw > balance { "失敗" } else { "成功" };
```


### 流程控制

Rust 的流程控制只有這幾種，而且都是表達式：

```rust
// if / else if / else：條件不加括號，分支一定要是 {} 區塊
if amount > balance {
    println!("餘額不足");
} else if amount == balance {
    println!("剛好清空");
} else {
    println!("OK");
}

// loop：無限迴圈，用 break 跳出；break 可以帶值
let mut retries = 0;
let result = loop {
    retries += 1;
    if retries == 3 {
        break retries * 10;   // loop 的值是 30
    }
};

// while：條件迴圈
let mut n = 10;
while n > 0 {
    n -= 1;
}

// for：遍歷任何可迭代的東西。這是最常用的迴圈，幾乎不會用 C 風格的索引迴圈
for i in 0..5 { }          // 0,1,2,3,4（不含 5）
for i in 0..=5 { }         // 0 到 5（含 5）
for i in (0..5).rev() { }  // 倒數
for memo in &memos { }     // 遍歷集合（第 3 章解釋為什麼要加 &）
for (i, memo) in memos.iter().enumerate() { }  // 同時拿索引

// 巢狀迴圈可以用標籤跳出外層
'outer: for a in 0..10 {
    for b in 0..10 {
        if a * b > 50 { break 'outer; }
    }
}
```

沒有 `do-while`，沒有三元運算子（用 `if` 表達式代替），沒有 `switch`（用更強的 `match`，第 5 章）。

### 巨集

`println!` 後面有 `!`，代表它是巨集（macro）而不是函式。
現階段你只要知道：巨集可以接受可變數量、可變型別的參數，所以 `println!` 能印任何東西。
常用的格式化語法：

```rust
let id = 1001;
println!("{}", id);        // 位置參數
println!("{id}");          // 直接寫變數名（Rust 1.58+）
println!("{id:>8}");       // 右對齊寬度 8
println!("{:?}", "debug"); // Debug 格式，之後印結構體會用到
println!("{fen:02}");      // 補零到兩位
```

## How：寫出第一筆交易

完整程式碼在 `code/ch01-first-transaction/`。

```rust
fn main() {
    let account_id: u32 = 1001;
    let owner = "王小明";
    let mut balance_cents: i64 = 150_000; // 1,500.00 元，以「分」為單位

    let deposit_cents: i64 = 25_050;      // 250.50 元
    balance_cents += deposit_cents;

    println!("帳戶 #{account_id}（{owner}）");
    println!("存入：{}", format_money(deposit_cents));
    println!("餘額：{}", format_money(balance_cents));

    let withdraw_cents: i64 = 200_000;
    if withdraw_cents > balance_cents {
        println!("提款 {} 失敗：餘額不足", format_money(withdraw_cents));
    } else {
        balance_cents -= withdraw_cents;
        println!("提款成功，餘額：{}", format_money(balance_cents));
    }

    let a: f64 = 0.1;
    let b: f64 = 0.2;
    println!("0.1 + 0.2 == 0.3 ? {}", a + b == 0.3);
}

fn format_money(cents: i64) -> String {
    let yuan = cents / 100;
    let fen = (cents % 100).abs();
    format!("{yuan}.{fen:02} 元")
}
```

執行：

```
$ cargo run
帳戶 #1001（王小明）
存入：250.50 元
餘額：1750.50 元
提款 2000.00 元 失敗：餘額不足
0.1 + 0.2 == 0.3 ? false
```

最後一行就是前言的事故一。我們的系統從第一行程式碼就不會有這個問題，因為金額是 `i64`，單位是分。

### 「以分為單位的整數」是業界慣例

這不是 Rust 特有的做法。Stripe、PayPal 的 API 金額欄位都是整數（最小貨幣單位）。
會計系統若需要更高精度（例如利率計算），會用十進位定點數（decimal），Rust 生態有 `rust_decimal` crate。
本書為了專注在語言本身，全程用 `i64` 分。

### 試著弄壞它

學 Rust 最有效的方法是故意寫錯，看編譯器說什麼。試試：

1. 把 `let mut balance_cents` 的 `mut` 拿掉。編譯器會指出你在哪一行試圖修改它，並建議加 `mut`。
2. 把 `let deposit_cents: i64` 改成 `i32`。`balance_cents += deposit_cents` 會失敗：Rust **不會**自動把 `i32` 轉成 `i64`，
   要寫 `deposit_cents as i64` 或 `i64::from(deposit_cents)`。這是刻意的：隱式轉型是很多溢位 bug 的來源。
3. 把 `format_money` 最後一行加上分號。函式會變成回傳 `()`，編譯器告訴你型別不符，而且會提示「也許你想移除分號」。

Rust 編譯器的錯誤訊息是全業界最好的之一。附錄 A 整理了常見的錯誤訊息怎麼讀。

## 回顧

- `cargo` 是你唯一需要記住的指令；`cargo check` 最快，寫程式時常按
- 變數預設不可變，要改加 `mut`
- 金額用 `i64` 以分為單位，不用浮點數；整數不會自動轉型
- 函式最後一個無分號表達式是回傳值

## 練習

1. 把 `format_money` 改成會印千分位：`1,750.50 元`。（提示：先轉成字串再從尾端每三位插一個逗號；或用迴圈。這題會讓你提早遇到 `String` 的操作，卡住沒關係，第 7 章學完迭代器會簡單很多。）
2. 加一個 `fn apply(balance: i64, delta: i64) -> i64`，正數是存款、負數是提款，用它取代 `main` 裡的兩段加減。
3. 試試 `let x: i32 = 2_147_483_647; let y = x + 1;` 用 `cargo run` 跟 `cargo run --release` 各跑一次，觀察差異。
